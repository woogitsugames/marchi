# プライバシーポリシー — MARCHIA: 王国の道

**最終更新日：** 2026年11月1日

本ポリシーは、Google PlayまたはApp Storeの掲載情報に記載された販売元が提供するモバイルゲーム **MARCHIA: Roads of the Kingdom**（以下「本ゲーム」）に適用されます。プライバシーに関するお問い合わせ先は **{{CONTACT_EMAIL}}** です。

## 1. 本ゲームが収集するデータ

本ゲームにアカウント、ログイン、個人情報は不要です。本ゲームから氏名、メールアドレス、位置情報、広告識別子、ゲーム履歴、端末識別子を収集または送信することはありません。利用状況の分析、プロファイリング、追跡も行いません。広告や広告SDKはありません。

## 2. 端末内のセーブデータ

ゲームの進行状況、マップの状態、資源、セーブ情報は、アプリの **IndexedDB** データベースを使用し、**お使いの端末内にのみ**保存されます。セーブデータをサーバーにアップロードせず、アカウントによる同期やクラウドセーブも提供しません。

アプリのストレージを消去するか、端末からアプリを削除すると、セーブデータを削除できます。アプリを取り除くだけではデータが残る場合があります。OSによるバックアップがある場合は、端末の設定およびOS提供者の規約が適用されます。

## 3. 完全版の買い切り購入

Google PlayまたはApp Storeで一度購入することにより、追加コンテンツを解放できる場合があります。決済は各ストアの運営者が独自のプライバシー条件に従って処理します。本ゲームは決済カード情報を収集しません。ストアは購入情報やアカウント情報を独自に処理する場合があります。

## 4. 共有と安全性

ゲームデータは端末外に送信されないため、第三者と共有しません。本ゲームには第三者の分析、広告、追跡サービスは含まれません。端末内のセーブデータの安全性は、端末とOSの保護機能にも依存します。
