# Zlecenie 01 — CI w GitHub Actions

Cel: każdy push i PR na `claude/**` i `gpt/**` uruchamia testy, a na żądanie buduje debug APK.

Do zrobienia (`.github/workflows/`):
1. `ci.yml` (push + pull_request):
   - Node 22, `npm ci`, cache npm.
   - `npm test` (headless symulacja; kończy się linią `SUMMARY passed=N failed=M`; kod wyjścia ≠ 0 przy błędzie).
   - `npm run typecheck`, `npm run build`.
   - `npm run bot` (bot musi wygrać misję 1; kod wyjścia 0).
   - `npm run perf:sim` → wynik dopisany do podsumowania joba (`$GITHUB_STEP_SUMMARY`).
   - Wyciągnij linię `SUMMARY` do podsumowania joba.
2. `apk.yml` (workflow_dispatch + tagi `v*`):
   - JDK 21 (temurin), Android SDK z `android-actions/setup-android` lub `tools/setup-android-sdk.sh`
     (platform android-36, build-tools 36.1.0).
   - `npm ci && npm run apk`, upload `dist-apk/*.apk` jako artefakt (retencja 14 dni).
   - Cache Gradle (`~/.gradle/caches`, `~/.gradle/wrapper`).
3. Badge statusu w `README.md` (utwórz krótkie README: nazwa gry, 3 zdania opisu PL, komendy z CLAUDE.md).

Kryteria akceptacji:
- Zielony run na PR; czerwony, gdy celowo zepsujesz test (sprawdź lokalnie w gałęzi roboczej, nie commituj zepsutego).
- APK do pobrania z artefaktów po ręcznym uruchomieniu.
- Bez sekretów w repo. Podpis release — poza zakresem (tylko debug).
