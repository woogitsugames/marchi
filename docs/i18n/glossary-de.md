## Round 05 terminology

| Polski / English | Deutsch | Usage |
| --- | --- | --- |
| ranga / rank | Rang | Settlement status, not a character level. |
| renoma / renown | Ansehen | Kept distinct from rank. |
| targ / market | Markt; Burgmarkt | The castle buys goods. |
| nasycenie / saturation | Sättigung | Falls by one unit every 10 seconds. |
| transza / tranche | Lieferung | A separately timed delivery within the contract. |
| kra, lód na moście / ice on the bridge | Eis auf der Brücke | A temporary closure; not bridge traffic congestion. |
| Buduj / Build | Bauen | Tool label. |
| Cofnij / Undo | Rückgängig; Zurück | Full wording in the refund message; compact Zurück on the timed undo button. |
| przepływ / flow | Ertrag | Silver earned per minute, not wagon traffic. |
| kasztelan / castellan | Kastellan | The castle's administrator. |
| księga / ledger | Buch; Siedlungsbuch | A settlement save slot. |
| Osada / Settlement | Siedlung | Rank 0. |
| Wieś targowa / Market village | Marktdorf | Rank 1. |
| Miasteczko / Small town | Kleinstadt | Rank 2. |
| Miasto / Town | Stadt | Rank 3. |
| Gród / Stronghold | Burgstadt | Rank 4; a fortified settlement, not a military-only outpost. |
| Stolica / Capital | Hauptstadt | Rank 5. |
| ryby / fish | Fisch | Mass commodity, as with Stein, Holzkohle, Malz and Bier. |

Counts use neutral labels where no noun inflects: `Warensorten {goods}`, `{n} verkauft`, `Kapazität`/`Platz für {n}`. Silber is a mass noun; rank and ledger numbers identify a single rank or ledger. Existing ICU-lite plurals remain unchanged. Tutorial tool names match the existing Weg label.
