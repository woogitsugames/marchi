## Round 05 terminology

| Polski / English | Português brasileiro | Usage |
| --- | --- | --- |
| ranga / rank | nível | Settlement development status, not an individual title. |
| renoma / renown | renome | Kept distinct from level. |
| targ / market | mercado; mercado do castelo | The castle buys goods. |
| nasycenie / saturation | saturação | Falls by one unit every 10 seconds. |
| transza / tranche | entrega | A separately timed delivery within the contract. |
| kra, lód na moście / ice on the bridge | gelo na ponte | Temporary bridge closure. |
| Buduj / Build | Construir | Tool label. |
| Cofnij / Undo | Desfazer | Timed action with a refund. |
| przepływ / flow | receita | Silver earned per minute, not wagon traffic. |
| kasztelan / castellan | castelão | The castle's administrator. |
| księga / ledger | livro | A settlement save slot. |
| Osada / Settlement | Povoado | Rank 0. |
| Wieś targowa / Market village | Aldeia mercantil | Rank 1. |
| Miasteczko / Small town | Vila | Rank 2. |
| Miasto / Town | Cidade | Rank 3. |
| Gród / Stronghold | Fortaleza | Rank 4. |
| Stolica / Capital | Capital | Rank 5. |
| ryby / fish | peixe | Mass commodity, as with pedra, carvão vegetal, malte and cerveja. |

Quantidade vendida is a count-independent label and works with all goods. Prata is a mass noun; rank and ledger numbers identify one level or ledger. Existing ICU-lite plurals remain unchanged. The tutorial names the existing Estrada tool; the contested-input message avoids singular/plural verb agreement.

## Round 06 — seasons and weather

| Polski / English | pt_BR |
| --- | --- |
| wiosna / spring | primavera |
| lato / summer | verão |

| zima / winter | inverno |
| roztopy / thaw | degelo |
| jesienny jarmark / autumn fair | feira de outono |

Thaw slows unpaved roads, not paved ones. Ice closes wooden bridges only; stone bridges stay open.
