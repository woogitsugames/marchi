### Niespójności i punkty do sprawdzenia

- W poleceniu pojawia się „posterunek”, natomiast aktualna etykieta `building.tradePost` brzmi „Punkt handlowy”. Ujednolicić nazewnictwo po decyzji redakcyjnej.
- „Sława” w poleceniu i „renoma” w `events.order.reward` mogą określać tę samą mechanikę; sprawdzić dane gry przed ujednoliceniem.
- Wpisy dla przęsła, kry, pieczęci, rangi i nadwyżki pochodzą z całych komunikatów, a nie samodzielnych nazw. Nie należy traktować całego komunikatu jako tłumaczenia pojedynczego słowa.
- Braki w wybranych 61 kluczach (liczba kluczy bez wartości): en: 0, de: 0, fr: 0, es: 0, it: 0, pt_BR: 0, nl: 0, sv: 0, tr: 0, ru: 0, uk: 0, ja: 0, ko: 0, zh_Hans: 0, ar: 0, hi: 0.

Nie oceniano poprawności językowej wszystkich istniejących przekładów ani znaczenia podobnych słów w innych kontekstach.
