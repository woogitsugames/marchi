# Przegląd dokumentacji misji I–XV

Baza `b020c577`; porównano pola kontraktów, startu, terminów, progów, budowli
oraz transz w `src/sim/missions.ts`, `missions-proposed.ts`, `missions-s2.ts`
i `src/sim/proposals/`, z odniesieniem do najnowszych decyzji w `DECISIONS.md`.
Pomiary strategii w starszych dokumentach są historyczne, nie ponawiano botów.

| Misja | Ustalenie / działanie |
| --- | --- |
| I | Brakowało `docs/missions/m1.md`; dodano zestawienie aktualnych danych. |
| II | Liczby startu, kontraktu i progów zgodne z danymi. |
| III | Skorygowano mylące „680 z 720 sekund”: deszcz 20–700 s, termin 660 s. |
| IV | Dawne progi w tabeli oznaczono jako historyczną propozycję; nagłówek zawiera aktualne D-109. |
| V–VI | Dane i progi zgodne; usunięto z VI nieaktualną uwagę o braku UI budowy. |
| VII–XIII | Liczby startu, kontraktu i progów w zestawieniach zgodne z kodem; dawnych wyników botów nie odtwarzano. |
| XIV | Brakowało pliku; dodano liczby i status prototypu poza `MISSIONS`. |
| XV | Brakowało pliku; dodano wartości kodu. Komentarz prototypu opisuje chleb i deski, ale kontrakt wymaga zboża i drewna. |

Nie zmieniano symulacji. XV wymaga decyzji projektowej przed integracją: opis
mechaniki, komentarz i aktualny zestaw budynków nie przedstawiają jednej misji.
