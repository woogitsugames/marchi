# MARCHIA — audio module, task 02

The audio files are original generated CC0 soundscapes and foley (not field recordings).
No audio plays before a trusted user gesture, and the module is **not** connected in
`src/main.ts`. The game loop mutates SimState in place; **do not pass the same
SimState object as both previous and current state**.

## Integration (the three important lines)

```ts
const audio = new AudioEngine(); bindAudioEngine(audio); // once at startup
let prevAudio = captureAudioState(loop.world.state); // before the first tick
loop.onTick = () => { observeSim(prevAudio, loop.world.state, audioCamera()); prevAudio = captureAudioState(loop.world.state); };
```

Call `void audio.init()` **directly from** a trusted `pointerdown`/`keydown`
handler (not a delayed timer). One possible camera adapter is:

```ts
const audioCamera = () => ({
  x: orbitTarget.x, z: orbitTarget.z, yaw: orbitAzimuth,
  mapWidth: loop.world.terrain.w, cellSize: loop.world.terrain.cellSize,
  water: loop.world.terrain.water, audibleRadius: 90,
});
```

`orbitTarget` and `orbitAzimuth` must come from the actual renderer implementation,
not `WorldView.camera`, which intentionally only exposes pan/zoom/follow methods.
If sim state is replaced by loading a save, recapture `prevAudio` immediately.

Use `audio.setVolume('master' | 'ambient' | 'sfx' | 'ui', 0..1)` from settings.
UI calls (only after `init()`): `audio.play('ui.wood')`, `audio.play('ui.paper')`,
`audio.play('ui.error')`.

The event bridge is read-only and uses two wagon mixer loops (dirt/cobble),
not one AudioNode per wagon. On a new browser tab it is silent until unlocked;
when hidden it smoothly mutes, and resumes on visibility return.

## Sound assets and licensing

All `.ogg` Vorbis and `.m4a` AAC files are generated by `tools/generate_audio.py`
and placed under `public/assets/audio/`. `.m4a` is the Safari fallback.
The output is copyright-free original procedural audio and is dedicated CC0-1.0;
no freesound/Sonniss material is included and no attribution is required.

- Ambient: 4 × 30–42 s stereo loops, around −24 LUFS.
- SFX: 19 mono foley/UI sounds, normalized to −6 dBFS peak (including 3 mechanical loops).
- Fade tails/heads and linear overlap blending eliminate loop discontinuities.
- Total size must be less than 4 MB for BOTH codecs together.

These sounds are intentionally subtle synthetic stand-ins for genuine documentary
field recordings. Replace them with verified CC0 recordings if a more realistic
sound palette is desired; update the asset ledger on replacement.
